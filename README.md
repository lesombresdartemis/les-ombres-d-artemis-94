# Les Ombres d’Artémis - Site V5.22

Version prête pour GitHub Pages.

## Publication

Déposer **tout le contenu de ce dossier** à la racine du dépôt GitHub :

- `index.html`
- le dossier `assets/`
- les cinq documents PDF

Puis activer GitHub Pages depuis la branche `main`, dossier `/ (root)`.

- formulaires d’adoption avec cases vides à cocher ;
- photos et contenus validés de la V5 conservés ;
- images externalisées dans `assets/images` pour faciliter l’envoi sur GitHub ;
- liens vers les PDF vérifiés.
